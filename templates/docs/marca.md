# Marca

Identidad visual para los informes y cuadros de mando del equipo. Claude la lee antes de dar estilo a un informe; si cambia la marca, se cambia aquí.

| Elemento | Valor |
|---|---|
| Color principal | `#000000` (el del logotipo) |
| Color de acento | `#000000` |
| Texto | `#000000` sobre blanco |
| Tipografía | Nombre de la fuente (y si está en Google Fonts) |
| Logotipo | Dirección o ruta del fichero (SVG si existe) |

Fuente: manual de marca o web corporativa, y quién lo revisó.
